# Vendored code: PFR entropy development

Everything under `InfoTheory/PFR/` is vendored from the
[PFR project](https://github.com/teorth/pfr) by Terence Tao and contributors
(Apache License 2.0; original copyright headers are retained in each file).

These files are the transitive import closure, within the PFR package, of the
four core entropy modules (`Entropy.Basic`, `Entropy.Measure`,
`Entropy.Kernel.Basic`, `Entropy.Kernel.MutualInfo`). Ruzsa-distance and
group-entropy files are deliberately excluded; re-add them by extending
`ENTRY_MODULES` in `scripts/vendor.sh` if ever needed.

## Rules

1. **Never edit vendored files by hand.** Any unavoidable deviation from
   upstream must be listed in the "Local modifications" log below (target:
   empty). This keeps re-syncs and the eventual Mathlib migration mechanical.
2. Original code imports the facade `InfoTheory.Entropy`, never
   `InfoTheory.PFR.*` directly.
3. The only transformation applied by `scripts/vendor.sh` is:
   - a two-line provenance header prepended to each file, and
   - import rewriting: `s/^((public |private |meta )?import (all )?)PFR\./\1InfoTheory.PFR./`
   Declaration names and namespaces are untouched (PFR declares in Mathlib-style
   namespaces, so fully-qualified names match what upstreaming would produce).

## Re-syncing / Mathlib upgrades

Follow PFR's Mathlib pin bumps; never bump Mathlib independently while vendored
files remain. To re-sync:

```
git clone https://github.com/teorth/pfr /tmp/pfr && git -C /tmp/pfr checkout <new-commit>
scripts/vendor.sh /tmp/pfr
# match PFR's pins:
#   copy /tmp/pfr/lean-toolchain over ./lean-toolchain
#   set the mathlib rev in lakefile.toml to PFR's lake-manifest.json mathlib rev
lake update mathlib && lake exe cache get && lake build
```

Commit re-syncs as a single dedicated commit touching only vendored files,
`VENDORED.md`, and the pins.

## Migration to pure Mathlib

When (parts of) this material lands in Mathlib: bump Mathlib past the landing
commit, delete the corresponding files under `InfoTheory/PFR/`, repoint the
imports in `InfoTheory/Entropy.lean` at the new Mathlib modules, rebuild.
Watch for renames introduced during Mathlib review (grep for the notations
`Hm[`, `H[`, `I[`, `Hk[`, `Ik[` to find affected call sites).
